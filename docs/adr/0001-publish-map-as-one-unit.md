# Publish each map as one unit

For the MVP, publishing a Map Draft makes its terrain, Map Features, and Lore visible together as one coherent Published Version. Lore Entries cannot be published independently; this avoids public features and terrain linking to mismatched lore states, at the cost of less granular publishing control.

## Pilot interpretation — 2026-10-04

The private pilot retains map-wide publication for terrain, Freehand Drawing, and road/river Feature Strokes. Lore and interactive content in the original rationale are deferred; they do not add pilot acceptance. See ADR 0006 and the current product specification.
